# Mosaic-Integration-Basic-Tutorial
This tutorial utilizes a real single-cell multimodal Mosaic dataset to demonstrate the Mosaic integration workflow, which primarily encompasses data normalization, quality control, a demonstration of various Mosaic integration methods, and basic downstream analysis.

You can get the tutorial data through this [link.](https://drive.google.com/file/d/1ZGstn5T2QEXVsxPcpVh9VpWXwSoSQRu5/view?usp=drive_link)
